# 領域用語

[文件索引](README.md)

- **旅程（Trip）**：一次旅遊紀錄的集合，具有日期範圍與當地時區，可跨日。
- **到訪事件（Event）**：一次已記錄的到訪，可以獨立保存或收在一本手記。相同地點每次到訪都有獨立事件。
- **日常足跡**：尚未收進手記的到訪事件，具有自己的日期與時區，可作為回憶來源。收進手記時沿用原事件識別碼。
- **地點（Place）**：使用者自行選用的地點資料；名稱相同不代表同一地點。
- **類別（Category）**：使用者用於描述到訪性質的分類。
- **下一站（NEXT）**：同一旅程中下一筆已記錄的事件，不表示中間絕無其他活動。
- **事件順序**：日期由早至晚，同日依使用者指定順序；缺少時間不補造時間。
- **照片（Photo）**：由本人保存、可放入旅程相簿或連到到訪事件與對話的圖片。
- **圖片線索**：從畫面、可見文字及圖說整理的搜尋資訊；候選地點與日期不等同已確認的到訪紀錄。
- **圖片來源**：支持畫面描述的照片；描述個人經歷時仍須對應已記錄的到訪事件。
- **旅程來源**：支持手記名稱、日期或描述的 Trip，不等同某次已發生的到訪或 NEXT 順序。
- **對話請求（ChatRequest）**：一段對話中的單次發問工作，保存獨立識別碼及處理狀態，供斷線後接續查詢。
- **草稿潤飾**：依原文調整語句的 AI 編輯操作；預覽與套用不會直接儲存旅程或事件。
- **足跡草稿（FootprintDraft）**：根據一段行程描述整理的待確認到訪資料；尚未成為正式事件，不能作為回憶查詢的證據。
- **記錄日期**：使用者為一段行程描述選定的日期，也是其中「今天／昨天」等相對日期的解讀基準。
- **批次加入**：使用者核對並勾選足跡草稿後，一次建立對應到訪事件；同一筆確認不重複建立事件。
