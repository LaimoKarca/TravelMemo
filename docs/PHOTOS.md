# 圖片手記與看圖回憶

## 把照片放進手記

旅程相簿預設收合，標題同列可直接拍照或從圖庫選取照片，實際選單依瀏覽器而異；箭頭用來展開照片清單。
照片可先放在旅程裡，再選擇連到某次到訪，不需要每張照片先填地點與日期。
使用封面操作選擇旅程代表照片，也可以上傳自訂封面。點縮圖可開啟檢視器；圖片與圖說都由本人管理。
相簿不設固定二十張的數量上限，仍須遵守檔案格式、單張大小與儲存空間限制。

支援 JPEG、PNG、WebP、HEIC／HEIF，不接受 SVG、動圖及影片。預設每張上傳最多 20 MiB，
最多五千萬像素。系統校正方向後轉成長邊最多 2,048 像素的 WebP，保存圖片最多 512 KiB，
縮圖最多 64 KiB；必要時降低品質與尺寸。完成後不保留原始檔案，下載取得的是壓縮後版本。
照片中的裝置資訊及 GPS 不會保留在瀏覽版本。

預設每帳號圖片空間 250 MiB，全站 5 GiB，包含圖片、縮圖與上傳預留空間。
空間不足時可刪除不需要的圖片。這是圖片空間限制，與每日 AI 對話次數無關。

## 圖片解析與搜尋

上傳完成後在背景讀取畫面，整理摘要、可見文字、物件／場景標籤、地點候選及不確定資訊。
日期只在有可用照片資訊時提出候選；不會從畫面補造日期，也不會自動改動到訪事件或行程順序。
使用者圖說與 AI 解析分開保存，圖說可用來更正或補充線索。

解析完成後重用結果，不會每次開啟相簿都重新付費辨識。失敗時照片仍可瀏覽，並可手動重試；
未設定模型或金鑰時，圖片保存與一般手記仍可使用。

回憶搜尋列的圖片圖示可開啟拍照／圖庫選單，可以同時輸入文字與圖片，也可以只選圖片。例如選擇甜點照片，尋找自己手記中
相符的抹茶、店面或招牌。搜尋根據圖片理解後的文字進行，沒有另外建立外觀相似度模型；
不是逐像素比對，也不保證找到同一種食物或同一個拍攝角度。

結果區分到訪事件與圖片來源。圖片若已連到事件，可回到事件查看日期與紀錄；
只放在旅程相簿裡的照片不能直接證明某次到訪日期。

## 聊天附圖

點聊天輸入區的圖片圖示，選擇相機或圖庫加入圖片，一則訊息最多四張，也可以不輸入文字。
圖片準備好後再發送；歷史對話保留附圖。若要納入旅程搜尋，使用「加入手記」選擇旅程與選填事件。
對話中的照片不會自動成為旅程資料。

助理可以描述畫面、閱讀可見文字；回答你何時到訪等個人經歷時，仍須取得本人旅程來源。
看不清楚的文字或不確定的地點會保留不確定性。圖片中的文字不會被當作系統指令執行。

長對話只帶必要的圖片描述與來源識別，不會將整份圖片內容放入摘要或反覆重送所有歷史圖片。
需要額外視覺細節時，只重新讀取指定圖片，每次問題限制追加處理次數。

## 刪除與備份

同一張照片可以同時被對話與手記引用。移除某個位置的連結不會影響其他引用；
明確刪除照片會使歷史引用顯示已刪除。沒有使用位置的暫存上傳會自動清理。

圖片存於私人圖片資料卷，Neo4j 保存關係與解析文字。備份必須同時保存資料庫及圖片卷，
只還原資料庫無法還原照片。操作見 [備份與還原](BACKUP_RESTORE.md)。

## 設定與費用

### API 概要

所有介面位於 `/api/v1`，沿用登入 Cookie 與寫入時的 CSRF 驗證：

| 介面 | 用途 |
| --- | --- |
| `POST /photos` | 以 `image/*` 二進位內容上傳一張圖片 |
| `GET /photos` | 按旅程、事件或對話列出本人圖片 |
| `GET /photos/{id}` | 取得狀態、圖說及解析資料 |
| `GET /photos/{id}/content`、`/thumbnail` | 取得私人保存圖片與縮圖 |
| `PATCH /photos/{id}` | 帶版本修改圖說 |
| `DELETE /photos/{id}` | 帶版本刪除圖片 |
| `POST /photos/{id}/retry` | 手動重新解析 |
| `/photos/{id}/bindings` | 加入或移除旅程、事件及對話關聯 |
| `/trips/{id}/photos/order`、`/cover` | 排序及封面設定 |

`POST /search` 接受選填的 `photo_ids`；文字與圖片至少一項。原有事件結果 `items` 保留，
圖片結果另放在 `photo_items`，每筆可包含已連結的事件。聊天訊息也接受 `photo_ids`，
回傳圖片附件及經驗證的圖片引用。跨帳號資源一律視為不存在。

### 模型與空間設定

`VISION_MODEL` 空白時沿用 `OPENAI_MODEL`。圖片解析需要支援圖片輸入的模型，API 呼叫會計費，
使用壓縮圖與保存結果來減少重複處理；`store=false` 不等同免除服務商其他資料保留政策。
一般日誌不保存完整照片、OCR 內容、私人圖說或金鑰。

圖片設定集中於 `.env.example` 的 `MEDIA_*` 參數，包含檔案大小、尺寸、空間及背景處理間隔。
本機預設保存於被 Git 忽略的 `data/media`；容器使用獨立 `media-data` 卷。
